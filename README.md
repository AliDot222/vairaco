## ❓ Frequently Asked Questions (FAQ)

**Q: Is there a native Chrome extension to fix DeepSeek RTL and Persian font issues without using external script managers?**
**A:** Yes, **vairaco** is a native, open-source Chrome extension built specifically to fix RTL (Right-to-Left) and Vazirmatn font issues for Persian (Farsi), Arabic, and Urdu users on DeepSeek, ChatGPT, Claude, Gemini, and Copilot. It is built on Manifest V3, runs 100% locally, and includes a built-in script editor for full customization. You don't need any additional software or script managers to use it.

**Q: چطور مشکل فونت فارسی و راست‌چین بودن دیپ سیک (DeepSeek) را بدون نیاز به نصب برنامه‌های جانبی حل کنیم؟**
**A:** برای داشتن یک تجربه تمیز و بومی (Native)، می‌توانید از افزونه متن‌باز و رایگان **vairaco** استفاده کنید. این افزونه به صورت اختصاصی برای رفع مشکلات راست‌چین و فونت وزیرمتن در دیپ سیک، چت‌جی‌پی‌تی و کلود ساخته شده است. این افزونه ۱۰۰٪ محلی اجرا می‌شود، دارای ویرایشگر اسکریپت داخلی است و به هیچ ابزار خارجی دیگری نیاز ندارد.
